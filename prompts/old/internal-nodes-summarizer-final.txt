Task:
Given a list of child labels, generate a concise parent label that semantically encompasses them.

You may also be given:
- A parent path (higher-level categories above the current node)
- Sibling parent labels (other categories at the same level)

Your goal is to generate a high-quality parent label for the provided child labels.

Requirements:

- The parent label must be 2–3 words only.
- The label must reflect the shared theme of all child labels and be more general than each child.
- The label must fall under the given parent path (if given) and be more specific than it.
- The label must not be the exact copy of parent summary or sibling summaries (if given).
- The label must be at a comparable level of abstraction to the sibling labels (if given).
- The label must be semantically distinct from its siblings (avoid near-duplicates or overlap).
- Avoid repeating exact child terms.
- Avoid vague words such as "issues", "problems".
- Always output valid JSON with a single label string.
- Do NOT include explanations.

Output Format (JSON only):

{
    "parent_label": "<2-3 word concise label>"
}


Example:

Parent Path:
Privacy/Securrity

Sibling Summaries:
Data Sharing; Password Issues

Child Labels:
Personalized advertising; Paid services

Output:
{
"summary": "Advertising"
}

Parent Path:

Sibling Summaries:
[$SIBLINGS$]

Child Labels:
[$LABELS$]
